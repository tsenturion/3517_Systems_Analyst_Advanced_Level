# Критерии приёмки US-001

## AC-001. Получение списка заявок

Given: в системе существуют зарегистрированные заявки.

When: клиент выполняет GET /tickets.

Then: сервер возвращает HTTP 200 и коллекцию items.

## AC-002. Фильтрация

Given: в системе существуют заявки разных статусов.

When: клиент выполняет GET /tickets?status=NEW.

Then: все возвращённые заявки имеют статус NEW.

## AC-003. Ограничение количества результатов

Given: в системе существуют не менее трёх заявок.

When: клиент выполняет GET /tickets?limit=2.

Then: коллекция содержит ровно две заявки.

## AC-004. Постраничная выдача

Given: данные не изменяются между запросами.

When: клиент запрашивает limit=1 с offset=0
и затем с offset=1.

Then: сервер возвращает разные заявки,
сохраняя согласованный порядок сортировки.

## AC-005. Пустой результат

Given: смещение равно количеству подходящих заявок.

When: клиент запрашивает следующую страницу.

Then: сервер возвращает HTTP 200,
пустой массив items и корректное значение total.

## AC-006. Некорректные параметры

When: клиент передаёт limit=0, limit=101,
offset=-1 или неизвестный статус.

Then: сервер возвращает HTTP 422.

## AC-007. Пользовательский интерфейс

Given: в системе существует более двадцати заявок.

When: пользователь открывает список
и переходит на следующую страницу.

Then: интерфейс отображает следующую группу
заявок и позволяет вернуться обратно.
