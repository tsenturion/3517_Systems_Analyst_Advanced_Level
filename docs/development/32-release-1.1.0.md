# HelpDesk 1.1.0

## Новая функциональность

Реализована постраничная навигация заявок.

Добавлена возможность запуска фронтенда
через сервер FastAPI.

## Инфраструктурные изменения

Добавлен Dockerfile.

Настроен GitHub Actions.

Реализованы автоматизированные проверки API.

Настроена публикация Docker-образов в GHCR.

## Связанные требования

US-001 — просмотр заявок.

TASK-006 — переключение страниц.

AC-007 — навигация между страницами.

CI-001 — автоматизация проверки и сборки.

## Известные ограничения

Рабочее хранилище — SQLite.

Браузерная приёмка выполняется вручную.

Обработчик Outbox запускается отдельно.

Интеграции с дополнительными хранилищами
не включены в поставляемый контейнер.
