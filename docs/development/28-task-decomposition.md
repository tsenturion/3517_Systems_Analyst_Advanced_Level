# Декомпозиция функциональности HelpDesk

## Epic EP-001

Управление заявками технической поддержки.

## Feature F-001

Просмотр и фильтрация заявок.

## User Story US-001

Как специалист технической поддержки,
я хочу получать список заявок с фильтрацией
по статусу и постраничной выдачей,
чтобы быстрее находить необходимые обращения.

## Задачи

| ID       | Задача                     | Ожидаемый результат                  |
| -------- | -------------------------- | ------------------------------------ |
| TASK-001 | Уточнить требования        | Согласованы правила получения заявок |
| TASK-002 | Спроектировать API         | Определён контракт GET /tickets      |
| TASK-003 | Доработать репозиторий     | Реализована выборка средствами SQL   |
| TASK-004 | Реализовать HTTP-операцию  | API принимает status, limit, offset  |
| TASK-005 | Подключить фронтенд        | Интерфейс отображает список и фильтр |
| TASK-006 | Реализовать навигацию      | Пользователь переключает страницы    |
| TASK-007 | Проверить функциональность | Получены результаты проверок         |
| TASK-008 | Обновить документацию      | Описаны реализованные возможности    |

## Зависимости

TASK-002 зависит от TASK-001.

TASK-003 и TASK-004 зависят от TASK-002.

TASK-005 и TASK-006 используют контракт TASK-002.

Интеграционная проверка TASK-007 зависит
от готовности проверяемых компонентов.

## Текущее состояние

API, фильтрация и серверная пагинация реализованы
в предыдущих разделах курса.

Фронтенд отображает первую страницу заявок.

Переключение страниц во фронтенде требует доработки.
