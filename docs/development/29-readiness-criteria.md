# Критерии готовности задач HelpDesk

## Definition of Ready (DoR)

- [ ] Определена пользовательская потребность.
- [ ] Описано ожидаемое поведение системы.
- [ ] Согласованы входные и выходные данные.
- [ ] Определены критерии приёмки.
- [ ] Выявлены зависимости и ограничения.
- [ ] Подготовлены необходимые контракты API.
- [ ] Задача может быть оценена командой.

## Definition of Done (DoD)

- [ ] Функциональность реализована.
- [ ] Критерии приёмки выполнены.
- [ ] Исходный код прошёл Code Review.
- [ ] Необходимые тесты пройдены.
- [ ] Проверена обратная совместимость.
- [ ] Документация актуализирована.
- [ ] Отсутствуют блокирующие дефекты.
- [ ] Изменения включены в согласованную ветку.
