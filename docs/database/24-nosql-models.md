# Модели NoSQL-хранилищ

| Модель          | СУБД      | Пример применения      |
| --------------- | --------- | ---------------------- |
| Ключ — значение | Redis     | Кеширование            |
| Документная     | MongoDB   | Интеграционные события |
| Графовая        | Neo4j     | Связи между объектами  |
| Широкие столбцы | Cassandra | Потоки событий         |

## Применение в HelpDesk

Redis:
временное хранение результатов HTTP-запросов.

MongoDB:
хранение и исследование копий событий Outbox.

PostgreSQL:
основные связанные данные предметной области.

SQLite:
текущее рабочее хранилище API.

## Принцип проектирования

Выбирать модель хранения на основании
структуры данных и сценариев доступа к ним.
