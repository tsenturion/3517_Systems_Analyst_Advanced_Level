# Выбор модели хранения данных HelpDesk

## Решение DB-001

Статус: принято для дальнейшей разработки.

## Основное хранилище

PostgreSQL.

Назначение: хранение связанных данных
предметной области HelpDesk.

## Распределение данных

| Данные                      | Предлагаемое хранилище |
| --------------------------- | ---------------------- |
| Пользователи                | PostgreSQL             |
| Категории                   | PostgreSQL             |
| Заявки                      | PostgreSQL             |
| Комментарии                 | PostgreSQL             |
| История статусов            | PostgreSQL             |
| Кеш результатов запросов    | Redis                  |
| События с гибкой структурой | MongoDB                |
| Технологические метрики     | Prometheus             |

## Причины выбора PostgreSQL

Поддержка связей между сущностями.

Контроль целостности данных.

Поддержка транзакционных операций.

Возможность сложных аналитических запросов.

## Дополнительные хранилища

Применяются при наличии обоснованных требований
к характеру и скорости доступа к информации.

## Текущее состояние

Реляционная структура PostgreSQL создана.

Предметные данные перенесены из SQLite.

Действующий API продолжает использовать SQLite.

Подключение дополнительных хранилищ
будет рассматриваться отдельно.
