# Требования к производительности HelpDesk

## Прогнозируемая нагрузка

Количество пользователей: 1000.

Среднее количество запросов за день: 24 000.

Прогнозируемая пиковая нагрузка: 20 RPS.

Целевая нагрузка с учётом запаса: 30 RPS.

Предварительный ориентир нагрузки на БД: 90 QPS.

## Прогноз роста данных

Период: 36 месяцев.

Количество заявок: 144 000.

Количество комментариев: 720 000.

Количество изменений статусов: 432 000.

## Требование DB-PERF-001

База данных должна поддерживать обработку
прогнозируемой нагрузки приложения.

Целевой ориентир: 90 SQL-операций в секунду
при согласованном распределении операций.

## Требование DB-PERF-002

Для получения коллекций большого объёма
необходимо предусмотреть эффективную пагинацию.

## Требование DB-PERF-003

Наиболее востребованные операции фильтрации
и сортировки должны исследоваться с помощью
планов выполнения запросов.

## Требование DB-PERF-004

Оптимизация запросов должна сохранять
корректность возвращаемых данных.

## Ограничения исследования

Использовались искусственно созданные заявки.

Исследовались преимущественно операции чтения.

Эксперименты проводились в локальной среде.

Целевые значения требуют согласования.

Комплексная производительность приложения
должна проверяться отдельным экспериментом.
