# Технологические метрики HelpDesk

## Цель наблюдения

Оценить состояние HTTP API системы технической
поддержки по результатам выполнения запросов.

## Объект наблюдения

Операция GET /tickets — получение списка заявок.

## Основные показатели

| Метрика                | Назначение                     |
| ---------------------- | ------------------------------ |
| Количество запросов    | Оценка активности              |
| Время ответа, мс       | Оценка скорости работы         |
| HTTP-статус            | Определение результата запроса |
| Количество ответов 5xx | Оценка серверных ошибок        |
| Доля ответов 5xx       | Относительная частота ошибок   |

## Источник данных

Измерения HTTP-запросов из Python-клиента.

## Учебные пороговые значения

Среднее время ответа: не более 200 мс.

Доля ответов 5xx: не более 1%.

## Условия применения

Пороговые значения установлены для упражнения.

Для эксплуатационной оценки необходимы
достаточное количество измерений, согласованный
период наблюдения и реалистичная нагрузка.
