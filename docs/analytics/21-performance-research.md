# Исследование производительности HelpDesk

## Проблематика

При увеличении количества одновременно
выполняемых запросов возможно увеличение
времени отклика приложения.

## Цель исследования

Определить влияние параллельных HTTP-запросов
на производительность HelpDesk.

## Гипотеза H-001

Увеличение количества одновременно выполняемых
запросов приводит к увеличению времени отклика API.

## Объект исследования

GET /tickets?limit=20&offset=0

## Режимы эксперимента

Режим baseline:
30 запросов, один клиентский поток.

Режим parallel:
30 запросов, до пяти клиентских потоков.

Каждый режим выполняется три раза.

## Исследуемые показатели

- Среднее время успешных запросов.
- Медиана времени ответа.
- P95 времени ответа.
- Пропускная способность.
- Количество ошибок.
- Доля успешных запросов в пределах 400 мс.

## Условия эксперимента

Одинаковая операция API.
Одинаковые параметры запроса.
Неизменный набор данных.
Одинаковая конфигурация приложения.

## Учебные критерии

P95 успешных запросов: до 400 мс.

Доля неуспешных попыток: до 1%.
