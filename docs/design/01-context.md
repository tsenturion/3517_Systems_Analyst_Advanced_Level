# HelpDesk — контекст проектирования

## Назначение

Система обработки заявок на техническую поддержку
сотрудников организации.

## Участники

Сотрудник, специалист поддержки, руководитель поддержки.

## Основные возможности

Создание заявки, просмотр состояния, назначение
исполнителя, обработка и закрытие заявки.

## Исходные условия

Пользователи работают через браузер.
Заявки должны сохраняться между сеансами.
История обработки должна быть доступна для просмотра.
Система должна допускать дальнейшее расширение.

## Результат проектирования

Согласованное описание устройства системы,
её основных частей и правил их взаимодействия.
