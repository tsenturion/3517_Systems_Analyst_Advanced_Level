# Проектные решения HelpDesk

## Решение DEC-001

Статус: принято для учебного проекта.

### Вопрос

Должна ли заявка иметь назначенного
исполнителя в момент создания?

### Вариант A

Исполнитель обязателен при создании заявки.

### Вариант B

Заявка создаётся без исполнителя.
Назначение производится позднее.

### Выбранный вариант

B.

### Обоснование

Сотрудник может создать заявку, даже если
доступный специалист ещё не определён.

### Последствия

Система должна поддерживать заявки
без назначенного исполнителя.

Назначение специалиста выполняется
как отдельная операция.

### Условие пересмотра

Изменение порядка распределения заявок
в организации.
