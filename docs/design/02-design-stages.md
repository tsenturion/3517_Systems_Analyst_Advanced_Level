# Этапы проектирования HelpDesk

## 1. Концептуальное проектирование

Определить основные части будущей системы,
их назначение и общие принципы взаимодействия.

## 2. Логическое проектирование

Определить внутренние правила работы приложения,
структуру информации и взаимодействие частей системы.

## 3. Детальное проектирование

Уточнить технические решения до уровня,
достаточного для реализации разработчиками.

## 4. Проверка проектных решений

Оценить согласованность решений, их реализуемость,
соответствие требованиям и ограничениям.

## Принцип работы

Решения уточняются итеративно по мере
получения новой информации.
