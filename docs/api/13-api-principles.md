# Принципы API HelpDesk

## Решение API-001

Статус: принято для учебного проекта.

## Выбранный подход

HTTP API с использованием принципов REST.

## Обоснование

Клиентские приложения взаимодействуют
с ресурсами через стандартные HTTP-методы.

Основным форматом обмена данными является JSON.

Результаты операций передаются через
HTTP-коды состояния и тела ответов.

## Реализованные операции

POST /tickets — создание заявки.

GET /tickets/{ticket_id} — получение заявки.

PATCH /tickets/{ticket_id} — изменение статуса.

## Основные принципы

Ресурсы имеют уникальные идентификаторы.

Операции соответствуют семантике HTTP-методов.

Запросы содержат информацию,
необходимую для их обработки.

Ошибки передаются через согласованные HTTP-коды.

## Условия пересмотра

Необходимость интеграции с корпоративными
сервисами, использующими SOAP.

Появление требований к дополнительным
стандартам обмена сообщениями.
