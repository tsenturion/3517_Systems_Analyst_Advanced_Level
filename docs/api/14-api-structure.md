# Структура API HelpDesk

## Базовый адрес

http://127.0.0.1:8000

## Ресурс Ticket

| Метод | Путь                 | Назначение             |
| ----- | -------------------- | ---------------------- |
| GET   | /tickets             | Получить список заявок |
| POST  | /tickets             | Создать заявку         |
| GET   | /tickets/{ticket_id} | Получить заявку        |
| PATCH | /tickets/{ticket_id} | Изменить статус        |

## Параметры списка заявок

status — необязательный фильтр по состоянию.

limit — максимальное количество возвращаемых заявок.

offset — количество пропускаемых записей.

## Пример запроса

GET /tickets?status=NEW&limit=5&offset=0

## Формат ответа коллекции

{
"items": [],
"total": 0,
"limit": 5,
"offset": 0
}

## Правила

Каждая заявка имеет уникальный идентификатор.

Список заявок допускает фильтрацию по статусу.

Результаты возвращаются в стабильном порядке.

Для коллекции применяется постраничная выдача.
