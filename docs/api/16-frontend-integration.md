# Интеграция фронтенда и бэкенда HelpDesk

## Компоненты

Фронтенд: HTML, CSS, JavaScript.

Бэкенд: Python, FastAPI.

Формат обмена: JSON.

## Соответствие действий и API

| Действие пользователя | HTTP-операция              |
| --------------------- | -------------------------- |
| Открыть список заявок | GET /tickets               |
| Создать заявку        | POST /tickets              |
| Изменить статус       | PATCH /tickets/{ticket_id} |

## Адреса разработки

Фронтенд: http://127.0.0.1:5500

Бэкенд: http://127.0.0.1:8000

## Правила взаимодействия

Фронтенд отправляет запросы через Fetch API.

Бэкенд выполняет операции с заявками.

Ответы передаются в формате JSON.

После изменения данных интерфейс обновляет список.

Ошибки API отображаются пользователю.
