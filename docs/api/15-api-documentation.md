# Документация REST API HelpDesk

## Назначение

Программный интерфейс предназначен для регистрации,
получения и изменения заявок технической поддержки.

## Базовый адрес

http://127.0.0.1:8000

## Операции

| Метод | Адрес                | Успешный ответ |
| ----- | -------------------- | -------------- |
| POST  | /tickets             | 201            |
| GET   | /tickets             | 200            |
| GET   | /tickets/{ticket_id} | 200            |
| PATCH | /tickets/{ticket_id} | 200            |

## Создание заявки

POST /tickets

Тело запроса:

```json
{
  "title": "Ошибка подключения",
  "description": "Не работает VPN",
  "creator_id": "user-anna",
  "category_id": "network"
}
```

Обязательные поля:
title, description, creator_id, category_id.

Результат: созданная заявка с уникальным id.

## Получение списка заявок

GET /tickets

Параметры:

| Параметр | Тип          | Значение                     |
| -------- | ------------ | ---------------------------- |
| status   | TicketStatus | Необязательный               |
| limit    | integer      | От 1 до 100, по умолчанию 20 |
| offset   | integer      | От 0, по умолчанию 0         |

Пример:

GET /tickets?status=NEW&limit=5&offset=0

Структура ответа:

```json
{
  "items": [],
  "total": 0,
  "limit": 5,
  "offset": 0
}
```

items содержит объекты заявок, если они найдены.

## Получение конкретной заявки

GET /tickets/{ticket_id}

Параметр ticket_id — идентификатор заявки.

Успешный ответ: JSON-представление заявки.

## Изменение состояния

PATCH /tickets/{ticket_id}

Тело запроса:

```json
{
  "status": "IN_PROGRESS",
  "user_id": "user-oleg"
}
```

Допустимые значения status:

NEW, IN_PROGRESS, RESOLVED, CLOSED.

Результат: обновлённая заявка.

## Ошибки

| Ситуация                      | HTTP-статус |
| ----------------------------- | ----------- |
| Некорректные входные данные   | 422         |
| Заявка отсутствует            | 404         |
| Непредвиденная ошибка сервера | 500         |

## Проверочные сценарии

| Сценарий                     | Ожидаемый результат  |
| ---------------------------- | -------------------- |
| Создать заявку               | 201, новый id        |
| Получить существующую заявку | 200                  |
| Изменить состояние           | 200, новый status    |
| Получить список с фильтром   | 200, коллекция items |
| Запросить неизвестный id     | 404                  |
| Передать limit=0             | 422                  |

## Ограничения текущей реализации

Аутентификация и авторизация пока не реализованы.

Проверка существования указанных пользователей
и категорий пока не выполняется.

Политика версионирования внешнего API
ещё не утверждена.

Допустимые переходы между состояниями
требуют дополнительной формализации.
