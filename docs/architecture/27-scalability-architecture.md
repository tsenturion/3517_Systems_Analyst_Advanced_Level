# Масштабирование архитектуры HelpDesk

## Решение ARCH-003

## Прогнозируемая нагрузка

Количество пользователей: 1000.

Целевая интенсивность: 30 RPS.

Предварительная нагрузка на БД: 90 QPS.

## Реализованные изменения

Перенос фильтрации на уровень базы данных.

Перенос пагинации на уровень базы данных.

Индексирование статуса заявки.

Сохранение существующего контракта REST API.

## Дальнейшие архитектурные изменения

Миграция рабочего хранилища на PostgreSQL.

Использование пула соединений.

Внедрение курсорной пагинации.

Интеграция Redis с серверной частью.

Автоматическая инвалидация кеша.

Масштабирование обработчиков RabbitMQ.

Горизонтальное масштабирование FastAPI.

## Критерии принятия решений

Результаты нагрузочного тестирования.

Время отклика API.

Пропускная способность.

Количество ошибок.

Использование вычислительных ресурсов.
