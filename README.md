# План практических заданий

На курсе «Системный аналитик. Продвинутый уровень» у нас будет 15 занятий за три недели. К каждому занятию я предлагаю одно практическое задание, чтобы вы могли закрепить материал. Сдача по желанию. [Программа курса](<./Программа курса !3517.docx>)

## Итоговый проект

Начните работу над проектом на первой неделе, с задания № 4. Выберите один учебный или рабочий сценарий и заведите для него папку. В заданиях № 5–14 возвращайтесь к этому сценарию, используйте результаты предыдущих работ и добавляйте новые материалы в ту же папку или репозиторий. К защите соберите материалы в один комплект.
